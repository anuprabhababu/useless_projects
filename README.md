 ###Overthinker 🎯


 Basic Details

Overthinker is a fun, AI-powered game that takes ordinary situations and turns them into an escalating overthinking rabbit hole. Players choose different perspectives, make branching decisions, add evidence, and use “MAKE IT WORSE” to push the situation from reasonable to completely unhinged, ending with a personalized overthinking score and report.

### Project Description

Overthinker is an AI-powered interactive game that turns ordinary everyday situations into increasingly ridiculous overthinking scenarios.
Instead of simply giving users an AI-generated answer, Overthinker creates a branching rabbit hole where users make choices, collect evidence, escalate situations, and ultimately discover how badly they have overthought something.
ChatGPT gives you an answer. Overthinker gives you a rabbit hole


### The Problem (that doesn't exist)
People sometimes receive completely normal messages or experience completely harmless situations and somehow turn them into full-scale investigations
There is probably nothing wrong.
But the human brain refuses to accept that.
Overthinker solves this extremely important problem that absolutely nobody asked us to solve.

### The Solution (that nobody asked for)
Overthinker lets users choose a personality, make suspicious decisions, collect evidence, and press 🔥 MAKE IT WORSE until they reach maximum overthinking.

###Implementation
 
For Software:

Frontend: React + Vite is used to build the interactive game interface, manage game state, branching choices, evidence, and the Overthinking Meter.

Backend: Python FastAPI handles API requests, game progression, scoring, and communication with the OpenAI API.
